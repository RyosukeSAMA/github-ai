Pantheon needs the web server

This page was opened as a local file. The Pantheon UI needs FastAPI so it can load styles, roles, workspace files, previews, and terminal output.

Start the server, then open http://127.0.0.1:8000/.

pantheon web --host 127.0.0.1 --port 8000
