## 新入口和边界

- Web Setup 区分配置与调用验证，测试结果 24 小时有效；更换模型、地址或密钥后不复用旧结果。引导可关闭或重新打开，示例任务需要用户点击发送。
- Web Setup 的 System credential storage 和 `pantheon credentials --migrate` 使用 macOS Keychain、Windows Credential Locker 或受支持的 Linux 密钥环。只在保存并读取核验成功后移除 `.env` 对应值；没有安全后端时不会冒充安全保存。系统存储的值不会被普通备份导出，换电脑需重新配置凭据。
- Web Info → Budgets、`pantheon budgets --policy policy.json` 和 SDK `p.services.budget` 使用同一工作区额度。0 表示不限。24 小时请求数统计包括失败、规划与摘要调用；同时发起的请求以 SQLite 事务预留额度。费用按用户填写的模型单价估算；没有单价时显示未知，开启金额额度后会拒绝未定价的新请求。预算启用客户端关闭 SDK 内部重试，失败或用量缺失的调用保留估算预留，避免静默退款。最终账单以服务商为准。
