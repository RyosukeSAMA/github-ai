- [ ] 系统凭据管理：安全后端可用性、显式迁移与 `.env` 兼容；日志及导出不暴露凭据。
- [ ] 可配置任务和日用量限制、费用估算与提醒；未知计费不冒充账单。
- [ ] 安装、更新和失败回退；原生 Windows 安装、后台启动、文件和终端能力。
- [ ] 任务检查点、失败步骤重试、完整结果归档；有外部副作用的步骤不静默重复。

- [ ] 图片/PDF 输入、图片生成、音频转文字；能力与服务商对应，缺少密钥时明确告知。
- [ ] Telegram、Slack、Discord：回调验证、账号/频道白名单、幂等去重、可配置回复；未配置时显示未连接。
