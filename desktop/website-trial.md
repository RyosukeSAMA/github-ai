# Pantheon website trial

Use a small static website you actually need to make and update. Use the same project folder or beta server for all three sessions. Keep the project material private and record measurements without copying API keys, prompts, or files into the trial notes.

## 1. Make and accept a first version

Install [Desktop beta](downloads.md), choose a project and connect one provider. Describe the page you need and two things you can check, such as mobile fit and a navigation button. Review and save the files. Open **Delivery checks**, run the checks and inspect the screenshots. Note which checks failed or were unverified before deciding whether to accept the result.

## 2. Change a decision

Change a brand choice and reject a layout or wording direction. In **Project overview**, confirm the replacement decision and register the current files. Save one open item for the next visit. Record how much information you had to re-enter to make the change.

## 3. Return after two or more days

Open **Project overview** and ask for the next outcome in a fresh task, such as “Add a pricing page.” Review the proposed continuation before sending. Check whether it finds the current files, follows the approved choices and leaves the rejected direction behind. Run the relevant checks again and review the new evidence.

After the third session, compare with the tool you normally use for this work. Note the step where you would switch tools, and which tool you would open first for the next update.
